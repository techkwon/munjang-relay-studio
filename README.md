# 문장잇기

이름과 이야기 분위기를 고르고 한 문단씩 넘겨 쓰는 한국어 릴레이 이야기 게임입니다.
가입 없이 한 화면에서 플레이하며, 작성 중인 원고는 사용 중인 브라우저에만 임시 저장됩니다.

## 주요 기능

- 2~8명 작가 순환
- 장르별 첫 문장과 이야기 장치
- 45초, 60초, 90초 타이머
- 자동 임시 저장과 새로고침 복원
- 키보드 단축키(`Ctrl/Command + Enter`), 복사, 공유
- 데스크톱과 모바일 반응형 화면

## 실행과 검증

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm test
```

`npm test`는 Sites 배포 빌드와 서버 렌더링 결과를 함께 검증합니다.
